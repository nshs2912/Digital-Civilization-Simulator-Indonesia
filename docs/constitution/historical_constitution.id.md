# Konstitusi Historis — v0.1

1. Bukti sebelum pernyataan.
2. Fakta dibedakan dari interpretasi.
3. Ketidakpastian harus terlihat.
4. Konteks temporal dan spasial wajib.
5. Tidak boleh membuat bukti historis.
6. Simulasi tidak boleh ditampilkan sebagai fakta sejarah.
7. Konflik antar-bukti harus dapat ditelusuri.
8. Peradaban mencakup manusia, komunitas, lingkungan, ekonomi, budaya, teknologi, dan institusi.
9. Pengetahuan harus berversi.
10. Agensi manusia dan kompleksitas sejarah harus dipertahankan.

Tiga waktu: Event Time, Source Time, Knowledge Time.

Evidence Strength, Claim Status, dan Model Confidence adalah konsep yang berbeda.

AI berada di atas evidence, bukan menggantikan evidence.
