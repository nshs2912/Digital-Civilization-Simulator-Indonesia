# Temporal & Spatial Intelligence — v0.1

## Temporal
The system distinguishes Event Time, Source Time, and Knowledge Time. A HistoricalPeriod must not be treated as an exact date. Temporal precision and uncertainty are explicit.

## Spatial
The system distinguishes CURRENT, HISTORICAL, ARCHAEOLOGICAL, CULTURAL_REGION, and ADMINISTRATIVE locations.

Modern Indonesian administrative boundaries **must not be projected backward automatically**.

Every temporal/spatial context must remain traceable to the relevant entity, claim, evidence, or source.
