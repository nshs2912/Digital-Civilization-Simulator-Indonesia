# Temporal & Spatial Intelligence — v0.1

## Temporal
Sistem membedakan Event Time, Source Time, dan Knowledge Time. HistoricalPeriod tidak boleh disamakan dengan tanggal pasti. Temporal precision dan uncertainty disimpan eksplisit.

## Spatial
Sistem membedakan CURRENT, HISTORICAL, ARCHAEOLOGICAL, CULTURAL_REGION, dan ADMINISTRATIVE.

Batas administratif Indonesia modern **tidak boleh otomatis diproyeksikan ke masa lalu**.

Semua temporal/spatial context harus dapat ditelusuri ke entity, claim, evidence, atau source yang relevan.
