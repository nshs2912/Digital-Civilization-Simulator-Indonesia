# Historical Integrity Engine — v0.1

The Integrity Engine is a gate before historical knowledge is used by AI.

## Checks
- unsupported claim
- missing evidence
- missing source
- invalid provenance
- temporal contradiction
- spatial contradiction
- anachronism
- simulation presented as fact
- confidence mismatch

If a record has an **integrity ERROR**, it must not be treated as validated historical fact.

**WARNINGS** may remain visible, but they must be exposed to both the system and the user.

The Integrity Engine does not determine historical truth absolutely. It checks whether the knowledge structure satisfies defined evidence, provenance, temporal, and spatial rules.
