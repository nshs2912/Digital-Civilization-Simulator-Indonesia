# Historical Integrity Engine — v0.1

Integrity Engine adalah gate sebelum pengetahuan historis digunakan oleh AI.

## Pemeriksaan
- unsupported claim
- missing evidence
- missing source
- invalid provenance
- temporal contradiction
- spatial contradiction
- anachronism
- simulation presented as fact
- confidence mismatch

Jika sebuah record memiliki **ERROR integritas**, record tersebut tidak boleh diperlakukan sebagai fakta historis tervalidasi.

**WARNING** tetap dapat ditampilkan, tetapi harus terlihat oleh sistem dan pengguna.

Integrity Engine tidak menentukan kebenaran sejarah secara absolut. Engine memeriksa apakah struktur pengetahuan memenuhi aturan evidence, provenance, temporal, dan spatial yang ditetapkan.
